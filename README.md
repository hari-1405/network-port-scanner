# Network Port Scanner

A Python-based TCP network port scanner designed for learning
networking and cybersecurity fundamentals.

## Features

- IP address / domain resolution
- TCP port scanning
- Custom port range
- Multithreaded scanning
- Open port detection
- Basic service identification
- Scan duration measurement
- Input validation

## Technologies

- Python 3
- Socket Programming
- TCP/IP Networking
- ThreadPoolExecutor
